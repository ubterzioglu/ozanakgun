# AGENTS.md - Ozan Akgün Portfolio & German Course Website

This document provides essential information for AI coding agents working on this project.

## Project Overview

This is a personal portfolio website for **Ozan Akgün**, a German language teacher based in Istanbul, Turkey. The website serves dual purposes:

1. **Portfolio/CV Page** (`/`) - Showcases professional background, experience, education, and certifications
2. **German Course Landing Page** (`/bilgi`) - Detailed landing page for German language courses (A1-A2-B1 levels, Goethe/TELC exam preparation)

The content is primarily in Turkish, targeting Turkish students learning German.

## Code Organization Patterns

### Page-Based Architecture
- Each major route has its own page component in `src/pages/`
- Page components are self-contained with inline data definitions
- No separate component library - UI elements are defined within pages

### Data Patterns
Pages define data as local constant arrays/objects:
- `personalInfo` - Contact and basic info
- `experience` - Work history
- `education` - Academic background
- `skills` - Professional skills
- `certifications` - Licenses and certificates
- `navLinks` - Navigation configuration
- `successStories` / `testimonials` - Student success stories

### Styling Approach
- **Tailwind CSS** for 90%+ of styling
- **Custom CSS** only when necessary (BilgiPage.css for smooth scroll animations)
- CSS variables defined in `index.css` for theming support
- Uses `tailwindcss-animate` plugin for animations

## Route Configuration

Routes are defined in `src/app.tsx`:

| Path | Component | Description |
|------|-----------|-------------|
| `/` | `HomePage` | Portfolio/CV with all professional info |
| `/bilgi` | `BilgiPage` | German course landing page |

## Path Aliases

Vite is configured with path aliasing:
- `@/` maps to `./src/` directory

Example: `import Something from '@/components/Something'`

## Tailwind Configuration

Custom theme extensions in `tailwind.config.js`:
- **Colors**: Full design system with semantic names (border, background, primary, etc.)
- **Border Radius**: Custom radius calculations based on `--radius` variable
- **Animations**: Accordion, caret-blink keyframes
- **Plugins**: tailwindcss-animate

CSS variables are defined in `index.css` supporting both light and dark modes (though dark mode is configured but not actively used).

## Development Guidelines

### Adding New Pages
1. Create new file in `src/pages/`
2. Add route in `src/app.tsx`
3. Update navigation links if needed

### Modifying Content
- All content data is inline in page components
- Update arrays like `experience`, `education`, `certifications` directly
- Images should be placed in `src/assets/`

### Styling Guidelines
- Prefer Tailwind utility classes
- Use `bg-gray-50` for alternate section backgrounds
- Use `max-w-6xl` or `max-w-7xl` for content containers
- Use `px-6` for consistent horizontal padding
- Follow the existing shadow pattern: `shadow-md hover:shadow-lg`

### Image Handling
- Profile images are imported as modules
- Background images use external Unsplash URLs
- PDF assets (CV) are referenced directly from root

## Important Notes

1. **No Testing Framework** - This project does not include any testing setup (Jest, Vitest, Playwright, etc.)

2. **No Linting Configuration** - No ESLint or Prettier configuration present

3. **No State Management** - Uses React useState/useEffect only, no Redux/Zustand

4. **No Backend** - Static site, no API calls

5. **Content Language** - Turkish is the primary content language

6. **Mobile-First** - Responsive design with Tailwind's mobile-first breakpoints
